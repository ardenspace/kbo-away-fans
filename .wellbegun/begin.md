## 이번 사이클의 델타 (착수 시점 요약)
아직 대화로 다듬기 전의 원재료다. 아래 일곱 묶음을 거치며 확정한다.

1. 로그인·회원가입 (구글·카카오·이메일), 닉네임·기본 프로필 이미지
2. 첫 진입 시 위치·알림 권한, 팀 선택 모달, 프로필 색이 팀 컬러로 전환
3. 홈 중단에 팀 경기 일정 + 최근 5경기 결과 요약 (선발 투수·점수·지역·날씨)
4. 하단 5탭 구조: 홈 / 배지 / 추천 / 좋아요 내역 / 마이페이지
5. 배지 — 구장 반경 진입 시 도장, 날짜·구장 기록, 누적 수에 따른 등급 상승
6. 좋아요 내역 — 추천과 같은 카테고리로 사용자가 누른 항목만
7. 마이페이지 — 프로필 색·닉네임·대표 이메일·로그인 기기 관리

### 상속 (사이클 1에서 그대로 유효)
- **플랫폼: 네이티브 앱, iOS와 Android 동시 출시** (크로스플랫폼 기술 사용).
- **과금: 완전 무료.** 수익화는 검증 이후 과제.
- **공유: OS 기본 공유만.** 장소 이름과 지도 링크를 OS 공유 시트로 내보낸다.
- **지도: 앱 안에서 띄운다.** 실시간 도보 길안내가 필요할 때만 외부 지도 앱으로.
- 멀티테넌시: 해당 없음 (단일 소비자 앱).

### 이번 사이클이 건드리는 항목 (논의 대상)
- **계정 모델: 계정 없이 시작** — 사이클 1은 "팀 선택은 기기에만 저장하고,
  스탬프/제보 단계에서 계정 도입을 검토한다"로 문을 열어 두었다. 델타 1번이
  바로 그 검토 시점이다.
- **데이터 소유권: 서버에 개인 데이터를 두지 않는다** — 계정·배지·좋아요가
  전부 개인 데이터 저장을 요구한다. 이 결정이 `decisions.md` 의
  [L] "콘텐츠는 서버 없이 정적 JSON 번들로 배포 / 백엔드 API 서버 기각"을
  지탱하고 있어서, 뒤집으면 그 기술 결정도 함께 재검토 대상이 된다.

### 사이클 1의 non-goal 중 이번에 뒤집는 후보
- **구장 방문 스탬프 / 10구장 완주 뱃지** — 델타 5번이 정면으로 되살린다.
