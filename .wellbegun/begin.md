# kbo-away-fans — begin (사이클 3)

## 이번 사이클의 델타

`visualizations/away-live-journey-preview.html`의 실시간 원정 여정과
`visualizations/favorite-team-theme.html`의 응원팀 컬러 체계를 Flutter 앱 본체에
전면 적용한다. 스플래시와 로고는 이번 사이클에서 다루지 않는다.

## Whose problem

대상은 기존과 같다. 야구장으로 이동하고 현장에서 경험을 쌓는 KBO 팬이다. 이번
사이클은 기능을 더하는 것보다, 사용자의 현재 상태가 화면의 색·이미지·움직임에
일관되게 반영되지 않는 문제를 고친다.

응원팀이 아직 없거나 고르고 싶지 않은 사용자도 미완성 온보딩 상태로 취급하지 않고
앱을 사용할 수 있어야 한다.

## Core journey (one)

사용자가 앱에 들어와 응원팀을 고르거나 `아직 응원팀이 없어요`를 선택한다. 팀을
고르면 그 팀의 대표색과 보조색이 앱 전역의 강조색이 된다. 팀 없이 쓰면 A 또는 B
기본 테마 계열을 쓰며, 각 계열 안에서 밝은/어두운 얼굴이 시간대에 따라 자동으로
전환된다.

- A 계열: `A1 · Lavender Play`(밝음) ↔ `A4 · Periwinkle Night`(어두움)
- B 계열: `B1 · Royal Fresh`(밝음) ↔ `B4 · Royal Night`(어두움)
- 팀을 나중에 선택하면 기본 테마보다 팀 테마가 우선한다.
- 다시 팀 없음으로 돌아오면 이전에 고른 기본 테마 계열을 복원한다.

홈은 경기 전 티켓 → 이동 중 경로 → 구장 근처 도착 신호 → 경기 중 라이브
전광판 → 경기 후 추천·스탬프로 이어지고, 우천 취소 때는 취소 의미와 실내 플랜B가
팀색보다 우선한다.

### Failure branch

- 팀을 고르지 않아도 특정 구단처럼 보이는 기본색을 강요하지 않는다.
- 시간대 분위기를 꺼도 경기 상태·우천 취소·추천 정보는 그대로 남는다.
- 모션 감소 환경에서는 계속 도는 장식 없이 사건의 결과가 즉시 읽힌다.
- 날씨·위치·일정 중 일부를 얻지 못해도 마지막으로 확정할 수 있는 상태와 기본
  기록 화면으로 저하한다.
- 처음 데이터가 없거나 오래 뒤 돌아온 경우에도 마지막 테마 선택은 즉시 복원하고,
  경기 신호가 없으면 꾸며 낸 라이브 상태 대신 기본 기록 홈을 보여 준다.
- 시간대 자동 전환은 한국 현지 시각의 낮/밤 얼굴을 고르되, 사용자가 설정에서
  밝음 또는 어두움을 직접 고르면 다시 `자동`으로 돌릴 때까지 그 선택을 우선한다.

## Success criteria

- 같은 계정에서 팀 선택·팀 없음 전환 뒤 앱의 모든 탭이 한 프레임워크의 테마로
  함께 바뀌고, 화면마다 이전 색이 남지 않는다.
- 팀 없음 사용자가 A/B 계열을 바꾸고 앱을 다시 열어도 선택이 유지된다.
- 경기 전·이동 중·구장 근처·경기 중·경기 후·우천 취소 얼굴이 같은 홈에서
  정보 손실 없이 전환된다.
- 밝은/어두운 시간대 전환과 모션 감소 상태에서 주요 문구와 CTA가 읽힌다.
- 첫 사용·무기록·2주 뒤 복귀에서도 팀 없음 프로필이 온보딩으로 되돌아가지 않고,
  마지막 A/B 계열과 자동/수동 밝기 설정으로 바로 진입한다.

## Non-goals

- 스플래시 화면과 로고 재디자인
- 새 경기·날씨·영업시간 데이터 원천 도입
- 실시간 중계 데이터나 이닝별 기록 기능 추가
- 사용자가 개별 색상을 직접 조합하는 테마 편집기
- 기존 계정·배지·좋아요·위치 판정 계약의 재설계
- 테마나 원정 상태를 외부로 공유·내보내는 새 흐름

## Product identity decisions

### 이전 사이클에서 그대로 유효

- iOS·Android 네이티브 앱을 Flutter로 함께 출시한다.
- 앱은 무료이며, 사용자 데이터는 Firebase에 두되 위치 좌표와 이력은 남기지 않는다.
- 소셜 로그인은 필수이고 구글·카카오·애플을 제공한다.
- 장소는 앱 안 지도와 OS 기본 공유를 사용한다.
- 배지는 홈·원정을 가리지 않는 10칸 구장 순례 기록이다.

### 이번 사이클에서 바뀐 답

- **응원팀 선택은 더 이상 앱 사용의 필수 조건이 아니다.** 팀 없음은 미완료 상태가
  아니라 정상 프로필 상태다.
- **팀 없음 사용자는 두 기본 테마 계열 중 하나를 쓴다.** 네 개의 개별 테마를
  고르는 것이 아니라 A/B 계열만 고르고, 밝고 어두운 얼굴은 시간대에 따라 바뀐다.
- **테마 우선순위는 의미가 먼저다.** 우천 취소·경고·성공 같은 시맨틱 상태 > 선택한
  응원팀 테마 > 팀 없음 기본 테마 순으로 역할을 나눈다.

## Product character

야구장으로 향하는 사람의 현재 상태가 화면의 이미지·색·움직임에 반영된다. 게임과
엔터테인먼트의 즐거움은 살리되, 팀색으로 화면 전체를 칠하거나 콘셉트 이름을 카피로
설명하지 않는다. 사건에 반응하는 모션을 보상으로 쓰고 장식은 절제한다.

시각 기준은 `away-live-journey-preview.html`의 한 홈 상태 흐름과
`favorite-team-theme.html`의 공통 쿨톤·절제된 팀색 사용이다. A/B 기본 계열은 둘 다
출시해 팀을 특정하지 않는 선택권을 실제로 제공한다.

## Expensive decision queue

- **팀/기본 테마 선택을 앱 전역에서 누가 소유하고 저장할 것인가** — 화면마다 색을
  고르면 탭·시트·네비게이터가 표류하고, 팀 없음 테마도 계정 간 격리가 필요하다;
  surfaced in bundles 2, 5, 7.
- **시간대 자동 전환과 사용자의 수동 override를 어떤 상태 계약으로 둘 것인가** —
  시스템 다크 모드·현지 시각·앱 설정·모션 감소가 함께 영향을 준다; surfaced in
  bundles 2, 7.
- **실시간 원정 상태를 어떤 우선순위와 경계 시각으로 판정할 것인가** — 일정·위치·
  날씨 신호가 어긋나거나 일부 실패할 수 있다; surfaced in bundles 2, 7.
